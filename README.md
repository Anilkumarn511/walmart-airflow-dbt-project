\# Walmart Data Engineering Project | Airflow \& dbt



I'm building this project to get hands-on experience with data engineering and understand how raw retail data can be transformed into useful information.



The project uses Walmart retail data and focuses on learning how Python, SQL, Apache Airflow, and dbt work together in a data pipeline.



My goal is to go beyond writing individual SQL queries and understand how a complete pipeline is organized, executed, and maintained.



\## What I'm Building



Through this project, I'm working towards building a pipeline that can:



\- Process Walmart retail data.

\- Use Apache Airflow to orchestrate pipeline tasks.

\- Use dbt to transform raw data into structured datasets.

\- Apply SQL transformations to prepare data for analysis.

\- Add data quality checks to identify potential issues.

\- Produce datasets that can be used for reporting and further analysis.



\## Tools \& Technologies



\- \*\*Python\*\* — for scripting and supporting pipeline tasks.

\- \*\*SQL\*\* — for querying and transforming data.

\- \*\*Apache Airflow\*\* — for managing and orchestrating workflows.

\- \*\*dbt\*\* — for organizing SQL transformations and testing data.

\- \*\*Git \& GitHub\*\* — for version control and project documentation.
